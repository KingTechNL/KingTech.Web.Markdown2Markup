# ImageGallery

As the Markdown2Markup project was originally created to allow for easy management and deployment of blogs, an image gallery is a must-have component.

## Example

Using the following markdown, the image gallery below is created:

```
[[[IG
	#Gggv_1
	Original garage.
	$loading=eager
	[https://www.beta.files.kingtech.nl/file/blog-images/IMG-20190411-WA0003-scaled.jpeg]
	[https://www.beta.files.kingtech.nl/file/blog-images/IMG-20190411-WA0004-scaled.jpeg]
	[https://www.beta.files.kingtech.nl/file/blog-images/IMG_20191215_094922-scaled.jpg]
]]]
```
