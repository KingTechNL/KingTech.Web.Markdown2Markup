# Abbreviations

Abbreviation can be declared by using `*[Abbreviation Label]: Abbreviation description`.

Abbreviation definition will be removed from the original document. Any Abbreviation label found in literals will be replaced by the abbreviation description. For example:

```
  *[HTML]: Hypertext Markup Language

  Later in a text we are using HTML and it becomes an abbr tag HTML.
```
