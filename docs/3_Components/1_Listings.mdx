# Listings
Basic bullit listings can be made by using the `-` symbol in combination with the right indentation.
For example:

```
 - item 1
 - item 2
   - item 2.1
   - item 2.2
     - item 2.2.1
 - item 3
```

Will result in the following:

- item 1
- item 2
  - item 2.1
  - item 2.2
    - item 2.2.1
- item 3

Its also possible to use numbers for listing. You can either manually number the items, or let the numbers be generated automatically.
The following example:

```
 1. item 1
 1. item 1
 1. item 2
 1. item 3
```

Wil result in:

1. item 1
1. item 1
1. item 2
1. item 3

It is not possible to use indentation in combination with numeric listings.


## Additional list types

In Addition to the standard markdown lists, MarkDig features the following list types: <br/>
**Alphabetic:** <br/>

```
  a. item 1
  a. item 2
  a. item 3
```

a. item 1
a. item 2
a. item 3

**Uppercase alphabetic:** <br/>

```
  A. item 1
  A. item 2
  A. item 3
```

A. item 1
A. item 2
A. item 3

**Roman numbers:** <br/>

```
  i. item 1
  i. item 2
  i. item 3
  i. item 4
```

i. item 1
i. item 2
i. item 3
i. item 4
