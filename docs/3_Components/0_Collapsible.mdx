# collapsible

The collapsible allows users to collapse any content that is inside it. This is a useful components to keep pages organized by hiding specific content untill clicked.

Using the following markdown, the collapsible content below is created:

```
<collapsible>
# This is a collapsible
This is the content part that can collapse.
</collapsible>
```
