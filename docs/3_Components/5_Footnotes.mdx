# Footnotes

Footnotes are small notes placed at the bottom of a page that provide extra information, citations, or clarifications related to specific parts of the main text. 

Basic footnotes can be added as shown in the example below:

```
 Here is a footnote reference,[^1] and another.[^2]
 This is another reference to [^1]

 [^1]: Here is the footnote.
 [^2]: And the other one.
```

And will result in the following:

&nbsp; Here is a footnote reference,[^1] and another.[^2] <br/>
&nbsp; This is another reference to [^1] 
[^1]: Here is the footnote.
[^2]: And the other one.

It is also possible to add longer footnotes. This way entire paragraphs can be embedded in a footnote.

```
 This is an example of a long footnote.[^longnote]

 [^longnote]: Here's one with multiple blocks.

     Subsequent paragraphs are indented to show that they belong to the previous footnote.

     The whole paragraph can be indented, or just the first line.  
     In this way, multi-paragraph footnotes work like multi-paragraph list items.

 This paragraph won't be part of the note, because it isn't indented.
```

Results in the following:

&nbsp; This is an example of a long footnote.[^longnote]

[^longnote]: Here's one with multiple blocks.

  Subsequent paragraphs are indented to show that they belong to the previous footnote.

  The whole paragraph can be indented, or just the first line.  
  In this way, multi-paragraph footnotes work like multi-paragraph list items.

&nbsp; This paragraph won't be part of the note, because it isn't indented.
