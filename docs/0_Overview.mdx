# Markdown2Markup

The KingTech Markdown2Markup project allows users and developers to to render markdown as properly formatted HTML. 

Markdown is a lightweight markup language that you can use to add formatting elements to plaintext text documents. It is easier to learn and master then HTML and JavaScript.
Basic markdown guides can be found [here](https://www.markdownguide.org/getting-started/).

This project is build around the <a href="https://github.com/xoofx/markdig">MarkDig</a> library by xoofx and supports all its elements. 
In addition to this extensive library, some custom components have been added.

The Markdown2Markup project is released as a [webservice](./1_WebService), allowing anyone to quickly setup new websites using Markdown as content source.
Additionally, the core logic is exported as a [NuGet library](./2_NuGet) for developers to include in their own (Blazor) webservice.

For the full source code and example projects, check out <a href="https://github.com/KingTechNL/KingTech.Web.FormGenerator">https://github.com/KingTechNL/KingTech.Web.FormGenerator</a>.
