# NuGet

The KingTech Markdown2Markup engine can be added to an existing Blazor webservice. 
For this, the core of the Markdown2Markup logic is made available as a NuGet package.

## Usage

In order to convert markdown to HTML, simply add the <a href="https://www.nuget.org/packages/KingTech.Web.Markdown2Markup">KingTech.Web.Markdown2Markup</a> package and add the following line to the <b><i>head</i></b> section in your <b><i>App.razor</i></b> file.

<pre>
    <code>
        &lt;Markdown2MarkupHeaders /&gt;
    </code>
</pre>
